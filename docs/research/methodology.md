# Research Methodology

Third-party projects are studied as research inputs, not copied as implementation sources.

```text
DISCOVER
→ LICENSE CHECK
→ PIN COMMIT
→ INVENTORY
→ EXTRACT CONCEPT
→ COMPARE
→ ADAPT
→ RECORD PROVENANCE
→ EVALUATE
```

Do not copy first and document later. Every adaptation must preserve the source reference, commit or version, license status, transformation, rationale and evaluation evidence. Research findings remain separate from runtime dependencies until the project explicitly approves an adaptation.
