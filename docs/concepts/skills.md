# Skills

Skills are reusable procedural knowledge. They explain how to perform a bounded class of work and may be used by more than one agent.

A skill must:

- have one clear purpose
- have activation conditions
- use progressive disclosure
- avoid duplicating agent identity
- avoid embedding platform-specific tool names unless adapter-specific
- support `references/` when detail becomes large

Skills provide method, not ownership. An agent remains responsible for deciding whether a skill applies and for producing the required contract. Phase 0.0 defines this concept but creates no production skills.
