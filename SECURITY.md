# Security Policy

Please report security issues privately rather than opening a public issue. Include:

- affected component
- security impact
- reproduction steps or proof of concept
- possible mitigation, if known

Security-sensitive areas include permissions, command execution, MCP and tool integrations, plugins and hooks, credential handling, the installer, and the self-improvement and promotion path.

Never commit credentials, tokens, private keys or other secrets. Remove sensitive data from reports and use the repository owner's private reporting channel when one is configured.

This project is pre-alpha; security response and supported versions are not yet formalized.
